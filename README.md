# 网申助手

网申助手是一个本地优先的 Chrome / Microsoft Edge 浏览器扩展，用于从个人简历生成资料模板，并辅助填写招聘网站的网申表单。

## 主要功能

- 解析 PDF、DOCX、TXT 简历，生成可编辑的本地模板
- 自动同步姓名、联系方式、个人身份、简介、亮点、实习经历和项目经历
- 管理多套简历模板，支持导入、导出、切换和重新导入
- 使用本地规则优先匹配网页字段，未匹配字段可交给配置的 AI 接口
- 支持 OpenAI 兼容接口，以及 OpenAI、DeepSeek、通义千问、Kimi、智谱 GLM、SiliconFlow 等预设
- 点击浏览器工具栏图标显示或隐藏悬浮助手
- 悬浮助手支持拖动、关闭，以及在同一个悬浮窗内打开管理面板
- 文本框、日期、下拉框、单选框等常见表单控件填写后提供高亮反馈
- 自动跳过密码、验证码、文件上传和提交类控件

扩展不会自动点击“提交申请”“下一步”“删除”或“同意协议”等高风险按钮。

## 安装

1. 下载或克隆本仓库。
2. 在 Edge 地址栏打开 `edge://extensions`，或在 Chrome 地址栏打开 `chrome://extensions`。
3. 开启右侧的“开发人员模式”。
4. 点击“加载解压缩的扩展”或“加载已解压的扩展程序”。
5. 选择本仓库目录 `Online-Application-Assistant`，也就是包含 `manifest.json` 的目录。
6. 将“网申助手”固定到浏览器工具栏，方便点击使用。

安装或重新加载扩展后，如果招聘网页已经打开，请刷新该网页。

## 使用方法

### 配置 AI

1. 点击工具栏中的“网申助手”图标。
2. 在管理面板的“AI 配置”中选择服务商，填写 API Key 和模型名称。
3. 如果使用其他服务商，选择自定义 OpenAI 兼容接口，并填写完整的 Chat Completions 地址。

### 导入和解析简历

1. 在管理面板打开“模板管理”。
2. 选择 PDF、DOCX 或 TXT 简历文件。
3. 点击“开始解析”。
4. 检查解析出的模板和“我的信息”；必要时可以直接编辑或导出 Excel 修改后重新导入。

解析成功后，当前模板中的基本信息、个人概况、实习经历和项目经历会同步到“我的信息”。

### 填写网申表单

1. 打开招聘网站的表单页面。
2. 点击浏览器工具栏中的“网申助手”图标。
3. 拖动悬浮助手到合适位置，选择当前模板。
4. 点击“一键 AI 填写”，完成后检查所有字段，再由你手动提交申请。

在 `edge://newtab`、`chrome://newtab` 等浏览器内部页面上，浏览器不允许扩展注入网页悬浮窗。此时点击图标会自动打开扩展管理页面；在普通网站页面上则显示悬浮助手。

## 本地演示

项目包含一个用于测试常见表单控件的演示页面。启动静态服务器：

```powershell
python -m http.server 8000
```

然后打开 `http://localhost:8000/demo/form.html`，刷新页面并点击扩展图标。

## 开发与验证

项目没有构建步骤，使用 Node.js 运行测试和类型检查：

```powershell
npm install
npm test
npm run typecheck
```

## 数据与隐私

- 简历模板、个人资料和 AI 配置保存在浏览器扩展的本地存储中。
- PDF、DOCX 简历先在本地提取文字，再将文字发送给你配置的 AI 服务商进行解析。
- 一键填写时，本地规则会优先处理；只有未匹配字段才会发送给 AI 服务商。
- API Key 只用于请求你选择的服务商，项目没有自建中转服务器。
- 备份默认不包含 API Key；密码、验证码、令牌等敏感字段会被过滤。
